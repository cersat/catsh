# Catsh

Самописный командный интерпретатор на Python. Работает как обычный шелл: набираешь команду — она выполняется. Поддерживает флаги, скрипты, псевдонимы команд и умеет запоминать их между запусками.

```
Catsh V0.10
C:\Users\you\python>ver
Catsh V0.10
```

## Запуск

```
python catsh.py
```

Флаги при запуске:

| Флаг | Что делает |
|---|---|
| `-s <файл>` | выполнить скрипт (список команд, по одной на строку) вместо интерактивного режима |
| `--debug` | включить отладочные сообщения (`[DEBUG] ...`) |
| `--fullerr` | не глушить ошибки — показывать полный traceback вместо короткого сообщения |
| `--ver` | напечатать версию и сразу выйти, не входя в интерактивный режим |

Пример:
```
python catsh.py -s myscript.cat --debug
```

## Команды

| Команда | Описание |
|---|---|
| `ver` | показать версию |
| `quit` | выйти из шелла |
| `type <файл>` | вывести содержимое файла |
| `catsee <папка> [-f -d -z -a N -s STR -r -e]` | показать содержимое папки |
| `echo <текст>` | вывести текст |
| `cd <папка> [<папка> ...]` | сменить текущую директорию (можно цепочкой) |
| `rem` | ничего не делает — комментарий в скриптах |
| `mdir <папка>` | создать папку |
| `rm <файл> [-r -d -s -q]` | удалить файл/папку |
| `move <src> <dst>` | переместить |
| `copy <src> <dst>` | скопировать |
| `touch <файл> <файл>...` | создать пустой файл (или обновить время изменения, если уже есть) |
| `run <скрипт>` | выполнить скрипт из-под интерактивной сессии |
| `run --out <команда>` | выполнить произвольную команду ОС напрямую (через `os.system`) |
| `cmddef [/? /d /c /l] <имя> <код>` | создать/удалить/проверить псевдоним команды, или показать список псевдонимов |
| `help` | список всех доступных команд |
| `cls` | очистить экран |
| `update` | скачать актуальную версию с GitHub и обновиться на месте, если она новее |
| `set var=value` | задать переменную для подстановки в текст команд |
| `env` | показать все текущие переменные |
| `bridge <room id> <nickname>` | подключиться к чату между двумя Catsh-сессиями через `ntfy.sh`, без портов и токенов |

### `catsee` — флаги

- `-f` — показывать файлы
- `-d` — показывать папки
- `-z` — показывать симлинки
- `-a N` — показать не больше N результатов
- `-s STR` — искать по подстроке в имени
- `-r` — рекурсивно спускаться в подпапки
- `-e` — не выводить сообщения об ошибках доступа к папкам (тихо пропускать недоступные)

Без флагов (кроме пути) — показывает всё с лимитом 10.

### `rm` — флаги

- `-r` — рекурсивное удаление (папка со всем содержимым). Требует подтверждения вводом `DeLeTe`
- `-d` — удалить пустую папку
- `-s` — «умный» режим: сам решает, `rmdir` или `unlink`, непустые папки не трогает
- `-q` — тихий режим, без вывода прогресса

### `run --out` — выполнение системных команд

```
run --out notepad
```

Передаёт команду напрямую операционной системе через `os.system`. ⚠️ Берёт только **первое слово** после `--out` — если нужна команда с аргументами, используй `cmddef` как обёртку, либо учитывай, что хвост из нескольких слов не передастся.

## Псевдонимы (`cmddef`)

Можно завести собственную команду как псевдоним на цепочку из уже существующих:

```
cmddef ll "catsee . -f -d"
```

Теперь `ll` работает как `catsee . -f -d`. Псевдонимы сохраняются в `%APPDATA%\Catsh\aliases.json` и переживают перезапуск шелла.

⚠️ Тело команды нужно брать в кавычки, если в нём больше одного слова. Без кавычек Catsh возьмёт только первое слово после имени, а остальное потеряется (см. раздел «Кавычки в аргументах» ниже).

```
cmddef /d ll     — удалить псевдоним
cmddef /?        — справка
cmddef /c        — проверить, не установлен ли одноимённый batch-cmddef
cmddef /l        — показать список всех псевдонимов (без встроенных команд, в отличие от `help`)
cmddef ll        — показать, во что разворачивается уже существующий псевдоним `ll`
```

## Скрипты

Скрипт — обычный текстовый файл, одна команда на строку:

```
rem это стартовый скрипт
echo Привет!
cd проекты
catsee . -f
```

Запуск: `python catsh.py -s script.cat` или командой `run script.cat` изнутри шелла.

## Кавычки в аргументах

Аргумент в двойных кавычках считается одним словом, даже если внутри есть пробелы:

```
type "мой файл.txt"
cmddef ll "catsee . -f -d"
```

Сами кавычки в итоговый аргумент не попадают.

## Переменные

Значение переменной подставляется в текст команды, если обрамить её имя знаками `%`:

```
set name=Серёга
echo Привет, %name%!
```
→ `Привет, Серёга!`

Если переменная не задана — `%имя%` остаётся в тексте как есть, без ошибки:
```
echo %xyz%
```
→ `%xyz%`

Чтобы напечатать сам символ `%` буквально, не запуская подстановку — экранируй его через `^`:
```
echo 50^% done
```
→ `50% done`

### Встроенные переменные

Кроме тех, что задаёшь через `set`, всегда доступны:

| Переменная | Значение |
|---|---|
| `%cwd%` | текущая директория Catsh |
| `%year%` `%month%` `%day%` | текущая дата |
| `%hour%` `%minute%` `%second%` | текущее время |
| `%input%` | останавливает выполнение и ждёт строку ввода с клавиатуры — введённое подставляется на место `%input%` |

Пример:
```
echo Как тебя зовут? %input%
```
→ печатает вопрос, ждёт ввод, подставляет ответ в ту же строку.

## Промпт

Приглашение командной строки — это просто переменная `prompt`, поэтому его можно менять через `set`:

```
set "prompt=%cwd% $"
```

Используй экранирование `^%`, если хочешь, чтобы переменная внутри промпта разворачивалась **каждый раз заново** (например, чтобы `%cwd%` показывал актуальный путь после `cd`), а не застыла на значении на момент вызова `set`:

```
set "prompt=^%cwd^% $"
```
По умолчанию промпт — `%cwd%>`.

## Мост между машинами (`bridge`)

```
bridge my-room-name Серёга
```

Соединяет две (или больше) сессии Catsh в общий чат, используя публичный сервис `ntfy.sh` как посредника. Не требует ни открытых портов, ни токенов, ни регистрации — обе стороны просто делают исходящие запросы к одному и тому же топику по его имени.

**Как это работает:**
- Первый, кто зашёл в комнату (`room id`), становится её создателем — остальные просто присоединяются к уже открытой.
- Всё, что печатаешь, уходит всем участникам комнаты под твоим ником.
- Входящие сообщения печатаются сразу, без задержки — используется потоковое соединение, а не периодический опрос.
- Набери `EXIT`, чтобы выйти из комнаты и вернуться к обычному Catsh.

⚠️ **Имя комнаты — это открытый публичный топик.** Любой, кто узнает `room id`, может подключиться и читать переписку. Не используй для чего-то приватного — выбирай длинное, случайное имя комнаты, если важна секретность.

## Обновление (`update`)

```
update
```

Скачивает актуальную версию `catsh.py` с GitHub (`cersat/catsh`, ветка `main`), сравнивает версию скачанного файла со своей (через служебный запуск `python catsh.py --ver`) и, если скачанная версия новее, заменяет себя ей на месте. Если версия та же или старше — ничего не меняется.

Использует только встроенные модули Python (`urllib.request`) — доустанавливать ничего не нужно, только доступ в интернет.

## Ошибки

Сообщения об ошибках начинаются с восклицательных знаков — их количество показывает уровень серьёзности:

| | Значит |
|---|---|
| `!` | предупреждение — команда продолжает работать, просто сообщает о частной проблеме (например, одна вложенная папка недоступна при рекурсивном `catsee -r`, но обход остальных продолжается) |
| `!!` | ошибка команды — конкретная команда не смогла выполниться (неверные аргументы, файл не найден, нет сети при `update`) и остановилась, но сам Catsh продолжает работать |
| `!!!` | ошибка самой оболочки — что-то пошло не так на уровне диспетчера команд (команда не найдена, зациклившийся псевдоним, непредвиденная системная ошибка) |

Флаг `--fullerr` при запуске отключает все эти аккуратные сообщения и показывает вместо них полный трейсбек Python — полезно для отладки самого Catsh, но не для повседневного использования.

## Пути

Относительные пути в командах считаются от текущей директории Catsh (`cd`), а не от рабочей директории процесса ОС.
